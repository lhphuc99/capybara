More of the UI can be resized, so long URLs, keys and store names show in full: drag the line between the Path and Host columns in the Network tab, between the keys and values in the Storage tab, or beside the list of stores in the Storage and State tabs. Double-click a line to reset it; widths are remembered. The Type column fits `websocket` without cutting it.
